Consejos rápidos

  • Online: crea o únete a una sala con código o QR (misma red no es necesaria; hace falta Internet).
  • Time’s Up: el host inicia y avanza las rondas.
  • Offline contrarreloj: countdown de 3 s solo en la primera palabra; luego inclina ↓ acierto / ↑ fallo.
  • Anuncios / ATT: si rechazas el seguimiento en iOS, el juego sigue funcionando.

Quick tips

  • Online: create or join a room with a code or QR (Internet required).

  • Offline timed: 3s countdown only on the first word; then tilt ↓ correct / ↑ pass.
  • Ads / ATT: if you decline tracking on iOS, the game still works.
